# 🎯 Goal: Azure Solutions Architect Expert (AZ‑305)

To earn it, you must:

* ✅ Pass **AZ‑305 (Architect exam)**

# 🧠 What You Must Learn

AZ‑305 focuses on **design (not configuration)**:

* Identity, governance, monitoring (25–30%)
* Data storage solutions (20–25%)
* Business continuity (10–15%)
* Infrastructure (compute + networking) (25–30%) [\[examcert.app\]](https://www.examcert.app/blog/az-305-study-plan-2026/)

Think:**“Why this service?” not “How to configure it?”**

# 📅 Detailed 6-Month Roadmap

## ✅ Month 1: Azure Foundations (2–3 hrs/day)

Goal: Build cloud + Azure basics

### Topics

* Cloud concepts (IaaS, PaaS, SaaS)
* Azure core services (VMs, storage, networking)
* Pricing, cost management
* Basic security & identity (Entra ID)

### Resources

* Microsoft Learn (AZ‑900 path)
* Hands-on: create VMs, storage accounts

👉 Outcome:

* Optional: Take AZ‑900 (not required but helpful)

***

## ✅ Months 2–3: AZ‑104 (Admin Level)

Goal: Learn how Azure actually works

### Topics

* Virtual networks, load balancers
* Azure AD (identity + RBAC)
* Storage accounts, backups
* Monitoring (Azure Monitor, Log Analytics)
* Compute (VMs, containers, App Services)

### Strategy

* Do labs for **every topic**
* Build a mini project:
  * VNet + VM + DB + monitoring

### Exam

* Take **AZ‑104 at end of Month 3**

👉 Why important:
AZ‑305 assumes **hands-on admin knowledge** [\[certdemand.com\]](https://certdemand.com/guides/azure-solutions-architect-az305-guide)

***

## ✅ Months 4–5: AZ‑305 (Architecture Focus)

Goal: Learn design thinking

### Weekly Structure (repeat pattern)

* Study concept
* Design solution
* Solve scenarios/questions

### Topics (deep dive)

1. **Identity & Governance**
   * Multi-tenant design
   * RBAC vs policies vs management groups
2. **Networking & Infrastructure**
   * Hub-spoke, hybrid, VPN, ExpressRoute
3. **Compute Design**
   * Choosing VMs vs App Services vs AKS
4. **Data Storage**
   * SQL vs Cosmos DB vs Storage
5. **Business Continuity**
   * Backup + disaster recovery strategies

👉 Key mindset:

* Trade-offs (cost vs performance vs security)
* Align with **Well-Architected Framework** [\[learn.microsoft.com\]](https://learn.microsoft.com/en-us/credentials/certifications/azure-solutions-architect/)

***

# 🧩 Key Success Tips (Critical)

### 1. Practice > Theory

AZ‑305 is scenario-based—you must **design solutions**, not memorize.

### 2. Build Projects

Even simple ones:

* Multi-tier app architecture
* Hybrid network design

### 3. Think Like an Architect

Always ask:

* Is this scalable?
* Is it secure?
* Is it cost-efficient?
