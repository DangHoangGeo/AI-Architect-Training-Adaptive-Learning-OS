# Quickstart

## First AI message

Paste this into your VS Code AI assistant:

```text
You are operating inside AI Architect Training OS V4. Read system/system_prompt.md, system/memory_protocol.md, system/session_commands.md, roadmap/master_12_week_roadmap.md, memory/profile.md, memory/progress.md, memory/mistakes.md, and memory/weak_areas.md. Then start today's training using /start-training.
```

## Daily commands

```text
/start-training
/check-understanding
/review-my-answer
/end-session
```

## Weekly commands

```text
/run-weekly-test
/start-workshop
/run-weekly-review
/update-portfolio
```

## Rule of use

If the AI gives generic advice, stop it and say:

```text
Use the memory folder, current roadmap position, and scoring rubric. Do not answer generically.
```
