# Portfolio

Copy polished workshop outputs here after weekly review.

Recommended structure:

```text
portfolio/
  week-01-basic-web-app/
    executive_summary.md
    architecture_diagram.png
    design.md
    key_decisions.md
    lessons_learned.md
```

Each portfolio item should prove:

- You can understand product context.
- You can design secure scalable systems.
- You can explain trade-offs.
- You can create deployable infrastructure.
- You can improve from feedback.
