# Week 01 Test — Cloud Architecture Fundamentals

## Purpose
Validate whether the learner can apply this week's concepts before starting the workshop: **Basic Web App Architecture**.

## Concepts tested
- Cloud service models and shared responsibility
- Azure regions, availability zones, and resource hierarchy
- Functional vs non-functional requirements
- Trade-off analysis across cost, scale, security, reliability
- Basic web application architecture

## Instructions
Answer in writing. Do not use one-word answers. Explain reasoning and trade-offs.

## Question 1 — Concept explanation (10 pts)
Explain the most important concept from this week in your own words. Include one Azure example and one non-example.

## Question 2 — Service selection (15 pts)
A team asks for a solution related to this week's topic. Choose an Azure service or pattern, reject one alternative, and explain the trade-off.

## Question 3 — Security and risk (15 pts)
Identify the biggest security risk in a design that ignores this week's topic. Propose two controls and one monitoring signal.

## Question 4 — Scenario design (30 pts)
Design a solution for this scenario:

> A mid-size company wants to launch a production workload in Azure. The workload must start small, be secure by default, support growth, and be understandable by a small operations team.

Your answer must include:

- Requirements and assumptions.
- Azure components.
- Data flow or request flow.
- Failure scenario.
- Cost consideration.

## Question 5 — PM reasoning (10 pts)
Define the MVP and one success metric. State one feature you would intentionally not build yet.

## Question 6 — Communication (20 pts)
Summarize your design for an executive in five bullet points. Avoid implementation jargon unless necessary.
