# Master 12-Week Roadmap

This roadmap aligns practical architecture training with Azure architect-level thinking: identity, governance, monitoring, data, business continuity, and infrastructure design.

## Week 01 — Cloud Architecture Fundamentals

**Goal:** Build the architect mindset: problem framing, requirements, trade-offs, and basic Azure building blocks.

**Core concepts:**
- Cloud service models and shared responsibility
- Azure regions, availability zones, and resource hierarchy
- Functional vs non-functional requirements
- Trade-off analysis across cost, scale, security, reliability
- Basic web application architecture

**Final workshop:** Basic Web App Architecture

**Exit criteria:**
- Complete five daily lessons.
- Pass weekly test with at least 75/100.
- Complete workshop artifacts and Bicep starter.
- Update memory and portfolio.
