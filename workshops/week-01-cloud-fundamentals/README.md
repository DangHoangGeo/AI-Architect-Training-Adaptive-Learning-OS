# Week 01 Workshop — Basic Web App Architecture

## Purpose
Apply Week 01 learning from **Cloud Architecture Fundamentals** in a realistic hands-on project.

## Business context
A growing organization wants a production-minded Azure solution that starts small but can evolve. The team needs both architectural clarity and deployable infrastructure.

## Functional requirements
- Public HTTPS web endpoint
- Static or simple dynamic content
- Basic telemetry

## Non-functional requirements
- Low cost for dev
- Secure defaults
- Clear ownership boundaries

## Required deliverables
- `pm_brief.md`
- `design.md`
- `architecture_decisions.md`
- `threat_model.md`
- `main.bicep`
- `modules/*.bicep`
- `review.md`
- `reflection.md`

## Completion criteria
- Design explains service choices and rejected alternatives.
- Security and cost are explicitly discussed.
- Bicep compiles after real deployment parameters are supplied.
- Review score is recorded in memory.
