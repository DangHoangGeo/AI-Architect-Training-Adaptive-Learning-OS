# Week 02 Workshop — Secure Network Foundation

## Purpose
Apply Week 02 learning from **Azure Networking and Secure Boundaries** in a realistic hands-on project.

## Business context
A growing organization wants a production-minded Azure solution that starts small but can evolve. The team needs both architectural clarity and deployable infrastructure.

## Functional requirements
- Network segmentation
- Private workload subnet
- Controlled inbound access

## Non-functional requirements
- Deny by default
- Document trust boundaries
- Prepare for private endpoints

## Required deliverables
- `pm_brief.md`
- `design.md`
- `architecture_decisions.md`
- `threat_model.md`
- `main.bicep`
- `modules/*.bicep`
- `review.md`
- `reflection.md`

## Completion criteria
- Design explains service choices and rejected alternatives.
- Security and cost are explicitly discussed.
- Bicep compiles after real deployment parameters are supplied.
- Review score is recorded in memory.
