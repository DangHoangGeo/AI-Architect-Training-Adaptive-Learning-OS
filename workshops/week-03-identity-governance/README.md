# Week 03 Workshop — Identity-enabled Enterprise App

## Purpose
Apply Week 03 learning from **Identity, Governance, and Access Control** in a realistic hands-on project.

## Business context
A growing organization wants a production-minded Azure solution that starts small but can evolve. The team needs both architectural clarity and deployable infrastructure.

## Functional requirements
- Managed identity access
- Key Vault integration
- RBAC-based access

## Non-functional requirements
- No hard-coded secrets
- Least privilege
- Audit access decisions

## Required deliverables
- `pm_brief.md`
- `design.md`
- `architecture_decisions.md`
- `threat_model.md`
- `main.bicep`
- `modules/*.bicep`
- `review.md`
- `reflection.md`

## Completion criteria
- Design explains service choices and rejected alternatives.
- Security and cost are explicitly discussed.
- Bicep compiles after real deployment parameters are supplied.
- Review score is recorded in memory.
