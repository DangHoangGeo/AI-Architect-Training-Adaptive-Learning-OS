# Week 09 Workshop — AI Document Processing System

## Purpose
Apply Week 09 learning from **AI System Design on Azure** in a realistic hands-on project.

## Business context
A growing organization wants a production-minded Azure solution that starts small but can evolve. The team needs both architectural clarity and deployable infrastructure.

## Functional requirements
- Document upload
- Async processing
- Searchable knowledge base
- AI-assisted answer flow

## Non-functional requirements
- Token cost control
- AI safety controls
- Human review option

## Required deliverables
- `pm_brief.md`
- `design.md`
- `architecture_decisions.md`
- `threat_model.md`
- `main.bicep`
- `modules/*.bicep`
- `review.md`
- `reflection.md`

## Completion criteria
- Design explains service choices and rejected alternatives.
- Security and cost are explicitly discussed.
- Bicep compiles after real deployment parameters are supplied.
- Review score is recorded in memory.
