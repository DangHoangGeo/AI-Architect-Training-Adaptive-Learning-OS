# Week 05 Workshop — Scalable E-commerce Platform

## Purpose
Apply Week 05 learning from **Scalability and Resilience Patterns** in a realistic hands-on project.

## Business context
A growing organization wants a production-minded Azure solution that starts small but can evolve. The team needs both architectural clarity and deployable infrastructure.

## Functional requirements
- Product browsing
- Order intake
- Async processing

## Non-functional requirements
- Traffic spike handling
- Queue-based decoupling
- Cost-aware scaling

## Required deliverables
- `pm_brief.md`
- `design.md`
- `architecture_decisions.md`
- `threat_model.md`
- `main.bicep`
- `modules/*.bicep`
- `review.md`
- `reflection.md`

## Completion criteria
- Design explains service choices and rejected alternatives.
- Security and cost are explicitly discussed.
- Bicep compiles after real deployment parameters are supplied.
- Review score is recorded in memory.
