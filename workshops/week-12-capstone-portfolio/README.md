# Week 12 Workshop — Capstone AI Governance Platform

## Purpose
Apply Week 12 learning from **Capstone: Executive-grade Architecture Portfolio** in a realistic hands-on project.

## Business context
A growing organization wants a production-minded Azure solution that starts small but can evolve. The team needs both architectural clarity and deployable infrastructure.

## Functional requirements
- AI governance portal
- Department-based access
- Model usage monitoring
- Approval workflow

## Non-functional requirements
- Executive reporting
- Security and compliance
- Portfolio-ready architecture

## Required deliverables
- `pm_brief.md`
- `design.md`
- `architecture_decisions.md`
- `threat_model.md`
- `main.bicep`
- `modules/*.bicep`
- `review.md`
- `reflection.md`

## Completion criteria
- Design explains service choices and rejected alternatives.
- Security and cost are explicitly discussed.
- Bicep compiles after real deployment parameters are supplied.
- Review score is recorded in memory.
